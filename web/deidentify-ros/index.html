ROSA .ros case de-identifier

Runs entirely in your browser. Nothing is uploaded — your files never leave this computer. (This page is just static HTML/JS served by GitHub Pages; there is no server.)

It removes the patient name, birthday, and acquisition date, and replaces every DICOM Series UID with a consistent token (so a display's SERIE_UID still matches its VOLUME path). It copies the image volumes (.img/.hdr/…) with each DICOM/<uid>/ folder renamed to its token, drops every DICOMFiles.zip (raw DICOM = full PHI), and excludes screenshots / qc. You get a clean .zip to share plus a private key file (keep it, never share) for re-linking to your own DICOM.

1. Pick the case folder

Select the whole case folder (the one containing the .ros and DICOM/). Or pick a single .ros file with the field below.

2. Subject ID

Pick a case folder or a .ros file to begin.

The key file is PHI. It maps the real name / UIDs back to the tokens — keep it private (do not put it in the shared zip).
